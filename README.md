# 🌐 Deepika Saini — Portfolio

This is my personal portfolio website built to showcase my skills, projects, and experience.
The website is designed with a dark theme and smooth animations, featuring a gradient background #deb5ec → #57435e.

✨ Features

🖤 Modern dark theme with gradient design

📜 Resume download button

📂 Projects showcase with smooth scroll + fade-in animations

📱 Responsive design for desktop & mobile

🍔 Hidden hamburger menu on scroll

🔗 Social links (LinkedIn, GitHub, Twitter, Instagram)

📞 Contact section with email & phone number

🛠️ Tech Stack

Frontend: React + Tailwind CSS

Animations: Framer Motion

UI Components: shadcn/ui, lucide-react

Deployment: GitHub Pages / Vercel / Netlify (whichever you choose)

📂 Sections

Home → Intro + Text Logo

About → Short bio & education

Projects → Featured work (Student Evaluation System, Sentiment Analysis, Job Analysis, Handwritten Digit Prediction, WPO11)

Contact → Email, phone number, and social links

Footer → “happy to chat :)”
